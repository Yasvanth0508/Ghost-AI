## Architecture Decisions

- `src/lib/project-access.ts` encapsulates Clerk user identity retrieval and Prisma project access resolution outside of page components for cleaner separation of concerns and reuse across future routes and Liveblocks auth endpoints.
- `/editor/[roomId]` acts as the standard dynamic workspace route parameter matching Liveblocks room identifiers.
- Collaborators are stored by email in PostgreSQL (`ProjectCollaborator` model) without a local user table; user profile enrichment (names and avatars) is retrieved dynamically via Clerk's Backend API (`clerkClient()`).
- `src/lib/liveblocks.ts` caches the `Liveblocks` Node client singleton and provides deterministic cursor color generation to ensure consistent collaborator colors across presence rendering.
- `POST /api/liveblocks-auth` dynamically authorizes sessions using `session.allow(roomId, session.FULL_ACCESS)` after checking Prisma project permissions.
- `src/components/canvas/liveblocks-canvas.tsx` encapsulates Liveblocks client context and suspense/error boundaries, keeping the parent page/layout free of client-only room setup logic.
- Canvas state synchronization leverages `@liveblocks/react-flow` (`useLiveblocksFlow`) with Suspense mode for seamless multiplayer sync of node positions, edges, deletions, and additions.
- Shape Drag-and-Drop uses standard HTML5 Drag and Drop with `application/reactflow` payloads containing the shape identifier and default dimensions, converted to canvas coordinates via `screenToFlowPosition()`.
- Shape Visual Geometry is rendered through dedicated SVG paths and CSS border primitives in `CanvasNodeComponent` for pixel-accurate geometry (Circle, Diamond, Pill, Cylinder, Hexagon, Rectangle) with centered text overlays and perimeter connection handles.
- Ghost Drag Preview provides instant client-side cursor tracking during canvas dragover using canvas-relative offset coordinates, rendering the matching dashed shape outline without touching persistent state.
- Inline Label Editing leverages React Flow's `updateNodeData` and `nodrag`/`nopan` to prevent canvas gesture conflicts while streaming label updates directly to Liveblocks storage.
- Node Color Customization utilizes React Flow's `NodeToolbar` and `NODE_COLORS` preset pairs to ensure consistent dark-theme contrast and instant multiplayer synchronization without server overhead.
- Custom Edge Routing uses `getSmoothStepPath` with `borderRadius: 8` for right-angle edges, coupled with `EdgeLabelRenderer` and a wider invisible interaction stroke for precision hover and selection.
- Canvas Ergonomics encapsulates viewport zooming and Liveblocks undo/redo inside `CanvasControlBar` and `useKeyboardShortcuts`, prioritizing user focus on the interactive canvas area while removing clutter (MiniMap).
- Starter Template Previews use standalone lightweight SVG vector renderers with dynamic `viewBox` computed from template node bounding boxes and node center coordinates, avoiding any React Flow runtime overhead in the dialog.
- Starter Template Import atomic replacement executes existing Liveblocks collaborative state mutations (`onDelete` for existing items, followed by `onNodesChange` and `onEdgesChange` with `add` actions), ensuring real-time multi-client synchronization and canvas history tracking before fitting the viewport.
- Presence Avatars & Live Cursors use Clerk user ID resolution (`useUser()`) to filter out self from collaborator presence, rendering up to 5 overlapping profile avatars with `+N` badge and conditional divider before Clerk `UserButton`. Live cursors broadcast React Flow coordinates and render colored SVG pointers with attached name badges.
- AI Workspace Sidebar uses modular component encapsulation (`AiSidebar`) with Radix `Tabs` separating interactive chat reasoning (`AI Architect`) and technical documentation generation (`Specs`), maintaining smooth full-height right panel transitions.
- Canvas Autosave & Persistence pattern stores lightweight blob URLs in PostgreSQL via Prisma (`canvasJsonPath`) while offloading actual canvas graph JSON payloads to Vercel Blob. Autosave is debounced to 1500ms and gated to empty Liveblocks rooms to prevent clobbering live collaborative sessions.
- Background task execution uses Trigger.dev v3 with `trigger.config.ts` targeting `src/trigger`. Tasks are triggered server-side via `tasks.trigger()`, tracked in Prisma via `TaskRun` (`runId`, `projectId`, `userId`), and authenticated to clients via run-scoped public tokens created using `auth.createPublicToken({ scopes: { read: { runs: [runId] } } })`.
